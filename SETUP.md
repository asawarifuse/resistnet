# ⚡ ResistNet — Setup Guide

## Prerequisites

- Python 3.10+
- Node.js 18+
- Git
- Docker (optional)

## Option 1: Quick Start (Local)

```bash
git clone https://github.com/asawarifuse/resistnet.git
cd resistnet

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

python src/api/main.py
